# Assets Directory

## Triathlon Background Image

To complete the login screen background setup, please add your triathlon image to this directory with the filename:

**`triathlon-background.jpg`**

The image should be:
- High resolution (recommended: 1920x1080 or higher)
- In JPG format
- Named exactly: `triathlon-background.jpg`

This image will be used as the background for the login and signup screens, showing the three triathlon disciplines (swimming, cycling, running) as described in the triptych image.
